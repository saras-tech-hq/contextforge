# Troubleshooting

- **Extract does nothing / error:** leave `chrome://`, the Web Store, and PDFs. Open an https article.
- **Load unpacked greyed out:** enable Developer mode on the extensions page.
- **manifest.json not found:** unzip fully; select the folder that *contains* the file, not the zip.
- **Clipboard failed:** click in the Markdown box and press Ctrl+C / Cmd+C, or use Save .md.
- **Need help:** https://github.com/saras-tech-hq/contextforge/issues

Local-first

Privacy

ContextForge is local-first. Page extraction, Markdown conversion, token estimation, and prompt packing run inside your browser.

Extension data

The last extract and license state are stored in chrome.storage.local on your device, bounded in size. No telemetry is collected or sent.

License validation

Validation runs only when you activate a key. The extension sends the license key and an instance name to the license Worker you configure; page content is never included.

What stays local

Extracted text leaves the extension only when you copy it or paste it into another tool. The MCP server reads pages on your machine and writes Markdown to the requesting client.

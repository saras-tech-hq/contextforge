Privacy

ContextForge is built with privacy by design. The core extension runs entirely locally — no data leaves your device unless you explicitly opt in.

Extension Data

All extraction data, license state, and prompt packing occur in chrome.storage.local or your local MCP server. No telemetry is sent unless you choose to share usage insights.

License Validation

License keys are validated via Lemon Squeezy's API or your Cloudflare Worker. Your license key is never stored server-side.

Optional Cloud Features

Prompt packing and token estimation may use Cloudflare Workers infrastructure, but no personally identifiable information is associated with these requests.

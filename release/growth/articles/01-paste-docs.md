# Draft: Stop pasting the whole documentation page into ChatGPT

**Status:** unpublished draft  
**SEO:** webpage to markdown for chatgpt, local markdown clipper  
**Claim limit:** describe ContextForge behavior; no “saves N% tokens.”

Raw copy-paste from MDN or Wikipedia includes menus, language lists, and footers. Models then waste context on chrome.

A local extractor that uses Readability keeps the article. ContextForge does that in a Manifest V3 popup and estimates tokens as length/4.

Install is Load unpacked from a GitHub ZIP. It is not a store button.

Limits: restricted Chrome pages, some SPAs, index pages.

# Phase 23 — share and feedback

**Feedback:** GitHub issue templates (`bug`, `extraction`, `feature`). No in-extension telemetry.

**Metrics (no new collection in the extension):**
- GitHub Release download count (Insights)
- Issue volume/type
- Voluntarily reported first/repeat uses in issues
